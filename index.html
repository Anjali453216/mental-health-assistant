🎯 Flow

How It Works

Intelligent orchestration routes every message through the right combination of agents in real time.

1
User Sends Message
The user types a message in the chat interface — a question, a feeling, or a cry for help.
2
Intent Classification
The Orchestrator analyses keywords and classifies intent: awareness, support, coping, or crisis.
3
Agent Activation
Distress Detection always runs. Other agents activate conditionally based on detected intent.
4
IBM Granite Generates
Each active agent sends a tailored prompt to IBM Granite 13B and receives a specialised response.
5
Response Synthesised
The Orchestrator picks the primary response and sends all results back to update the live UI.
